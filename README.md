## 📋 Описание

**FunPay Cortex** — мощный Telegram-бот для автоматизации торговли на FunPay. Автовыдача, автоподнятие лотов, автоответы, вечный онлайн и кастомные плагины.

---

## ✨ Основные возможности

- 🤖 **Автовыдача** — автоматическая выдача товаров
- 📈 **Автоподнятие лотов** — обходит лимиты FunPay
- 💬 **Автоответчик** — макросы и авто-команды
- 📱 **Управление через Telegram** — интерактивная панель
- 🧩 **Плагины** — расширяйте функционал
- 🌐 **Мультиязычность** — RU/EN/UA
- 🔄 **Авто-обновления** — всегда актуальная версия

## 🚀 Быстрая установка

### Windows

1. Скачай Python
2. Скачай архив проекта
3. Распакуй и выполни в командной строке:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

### Linux

```bash
sudo apt update && sudo apt install python3 python3-pip python3-venv git -y
git clone https://github.com/QuestGuideRF/funpaycortex.git
cd funpaycortex
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
```

---

## 📖 Использование

1. Запусти `python main.py`
2. Следуй инструкциям в консоли
3. Управляй ботом через Telegram: `/start`

---

## 🧩 Плагины

Добавление плагинов через Telegram-бота:
1. Меню 🧩 Плагины → ➕ Добавить
2. Отправь `.py`-файл плагина
3. Готово!
